## What the migrations create

Each table below: key, columns (type; constraint), indexes, the one writer per row or column (detailed in TABLE-OWNERS.md), the RLS class, and the source. RLS classes: **S** service only (RLS on, no policy for `anon` or `authenticated`); **C** client-facing (RLS on, read-only select policy for a client user limited to their clients' rows, Question 1); **A** append-only (S plus the T7 grants and trigger); **R** reference (S, no write grant to any role). The writer roles follow the privilege matrix.
