# Issues

`docs/issues/<ID>-<n>.md` from `build-plan/templates/ISSUE.md`: a dependency that does not behave as
its handoff says, filed by `/build-session` or `/fix-session` with the failing test that shows it.
The session stops after filing it, and the owning session fixes it.

An open question that blocks the session is `docs/issues/<ID>-q<n>.md`: the question, the options
and a recommendation; it lets the stop gate end the session.
