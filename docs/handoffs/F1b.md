## For the sessions that depend on this

- **F2, F3, F8 and `/contract-change`**: run on the lane branch (`sb/F2`, `sb/F3`, `sb/F8`, `sb/CC-<proposal>`) or start with `ALLOW_CONTRACT_EDITS=1`. The guard lets those through and blocks a bare `sb/CC-`. A contract-change sets `Applied: <sha>` alone, in a second commit (step 7).
- **Build and fix sessions**: a question you stop on goes in `docs/issues/<ID>-q<n>.md`. The stop gate lets you stop only for a proposal or issue filed in this session, and only while the code is as it was at that stop. It gates every change outside `docs/` and `build-plan/`, and also a docs lane's README. With no merge base it runs the full check on every stop. A session armed by the old hook (an empty arm file) gets only the 3-round escape.
- **Reviewers in a shallow clone**: `git fetch --unshallow origin +refs/heads/main:refs/remotes/origin/main` before `git diff origin/main...HEAD`; `make check` and the policy scripts fetch by themselves (`SB_NO_FETCH=1` stops them).
- **Every lane**: `make bootstrap` is the install step; CI checks formatting before `make up` (a Prettier upgrade such as Dependabot #11's needs `make fmt` on its branch); a lane that changes a mirrored pin runs the Mirror images workflow on its branch (Actions, Run workflow) before its CI.

## Operations

- **`make bootstrap` in the cloud**: start dockerd, then `make bootstrap`.
